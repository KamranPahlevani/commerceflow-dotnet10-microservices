# CommerceFlow

CommerceFlow is the reference project for a professional .NET 10 course focused on modern backend engineering, Clean Architecture, Domain-Driven Design, distributed systems, and microservices.

## Technology Baseline

- .NET 10
- ASP.NET Core
- C#
- Clean Architecture
- Domain-Driven Design
- CQRS
- Event-Driven Architecture
- Microservices

## Repository Structure

- `src/` — Production source code
- `tests/` — Automated tests
- `docs/` — Course and architecture documentation
